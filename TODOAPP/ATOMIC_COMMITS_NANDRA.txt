ATOMIC COMMITS — IMPLEMENTASI NANDRA
=====================================

Jalankan setiap blok dari root proyek TODOAPP. Setiap perintah git commit
memasukkan judul dan deskripsi berbahasa Indonesia ke dalam commit message.
PRD_pert3_v2.md tidak termasuk ke dalam commit mana pun.


1. Atomic commit API
--------------------

git add app/Services/ProjectDeletionService.php
git add app/Http/Controllers/ProjectController.php
git commit -m "feat(project-deletion): add atomic API project deletion" -m "Deskripsi:
Mengimplementasikan penghapusan project API yang atomic dengan database transaction.

Perubahan:
- Menambahkan ProjectDeletionService sebagai satu sumber logika penghapusan project.
- Menghapus seluruh task berdasarkan project_id.
- Menghapus seluruh project membership berdasarkan project_id.
- Menghapus project setelah data turunannya berhasil dihapus.
- Membungkus seluruh proses dengan DB::transaction() agar kegagalan memicu rollback.
- Mengubah endpoint hapus project API agar memakai service tersebut.
- Mengembalikan respons JSON status 500 berbahasa Indonesia saat transaksi gagal."
